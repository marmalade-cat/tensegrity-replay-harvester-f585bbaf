TensegrityReplayHarvester

Prototype web tool that demonstrates extracting per-module pose/orientation time-series from small pasted inputs (CSV or JSON), normalizing timestamps, and exporting replay-ready CSV/JSON. Open index.html in a browser, paste sample data or use provided examples, press Parse, then Export.

This is a compact demo. It does not download files automatically—treat online PDFs/ZIPs as untrusted and extract data into the input box before using.

No dependencies. Example sources are synthetic and included in the UI.
